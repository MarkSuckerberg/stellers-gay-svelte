So, this is just a collection of resources I have used in the past that I personally find at the very least interesting,
but possibly even fundamental to me learning the skills I have now. I plan on keeping this updated whenever I find something
new, or, more likely, remember something that I had forgotten when I first wrote this.

## Table of Contents

## Learning to Code

My forte. This is what I went to school for, what I have been working in for the past... however many years it's been
since 2018 when you're reading this.

### [Advent of Code](https://adventofcode.com)

Wintertime programming challenge that gets progressively harder as you go. Encourages you to think algorithmically, and of
course lets you use whichever programming language you like the best.

### [Bitburner (Game)](https://bitburner-official.github.io/)

A game that I found somewhat interesting. It's sort of like hacknet, but involving a lot more scripting to automate things.
I truthfully didn't get suuuuper far, but it's fun if you're into that sort of thing. All the code is javascript/typescript though,
so be warned if you have the classic hatred of JS in any and all forms, even if typescript is really nice actually.

### [C# Crash Course](https://rbwhitaker.wikidot.com/c-sharp-tutorials)

This might be out of date or even a bad tutorial by someone's standards (I think it's more than fine), but this is the tutorial
that taught me C#. At the time, I had only worked with Dream Maker, so I had some knowledge to begin with, but I think it
would be helpful to those at any level of experience.

### [Game Programming Patterns](https://gameprogrammingpatterns.com/)

This one is probably the link I send to the most people. I believe I've even linked it from this very blog. Even if you're
not strictly working on a game dev project, there is lots of useful knowledge and patterns that you might learn for the first
time, or learn how to use more effectively in your work.

### [Mozilla Dev Network Docs](https://developer.mozilla.org/en-US/docs/Web)

INFINITELY helpful. It's not really something I'd go to to learn HTML/CSS/JS from the ground up, but it's the ideal reference
that outlines pretty much everything to do with the modern incarnations of the three languages, as well as the HTTP protocol
in general.

### [Red Blob Games](https://www.redblobgames.com/)

This site is honestly AWESOME. It's definitely not a beginner tutorial site, but it's got so many neat examples and guides that
relate to procedural generation, grids, pathfinding, and more that are right up my alley. I recommend it heavily if you like a
bit of math in your coding.

### [Structural Patterns](https://refactoring.guru/design-patterns/structural-patterns)

I truthfully have never read this, but it was in my bookmarks and looks promising, so have at it.

### [The 20 Games Challenge](https://20_games_challenge.gitlab.io/challenge/)

I've seen multiple versions of this over the years, and truthfully I've never completed it myself, but the idea really resonates
with me, and I believe it could really help someone learn game development. The name is a little misleading, I'll say, since
they really only outline 10 directly, but even then, it sets some nice goal posts to get you into the mindset of developing games.
Keeping a steady pace with results that matter to you is always important.

### [Zachtronics Games](https://store.steampowered.com/developer/zachtronics/)

Truthfully, I've only played [TIS-100](https://store.steampowered.com/app/370360/TIS100) and [Shenzen IO](https://store.steampowered.com/app/504210/SHENZHEN_IO),
but both games were really fun to play. TIS-100 was about programming this rather uniquely formatted CPU with simple assembly code,
and Shenzen IO was a neat abstraction of making things with components like you realistically would when making a microelectronics
project, including, most importantly, pouring over datasheets to find out how you do certain things.

## Coding Resources

### [Cloudflare Workers](https://developers.cloudflare.com/workers/)

I hate to shill big companies, but this site literally exists because of Cloudflare Workers. It's got a fairly lenient free plan and allows you
to host a website "serverless" while still allowing for plenty of server-side functionality such as keeping things secret, doing server-side requests,
doing routing, and more. Specifically, I like using it with the sveltekit adapter since I like working with sveltekit.

### [Cyberchef](https://cyberchef.org/)

Super useful toolkit that basically lets you encode and decode data to your heart's content. I don't use it often, but when I need to,
it's just awesome to have.

### [DBeaver Community](https://dbeaver.io/)

A pretty good DBMS that lets you access and manage all sorts of different databases. Requires a paid version for some types
of database, but for mariaDB, postgreSQL, sqlite, and such, it seems to work pretty well. Supports linux!

### [Hello, World! In Every Programming Language](https://github.com/leachim6/hello-world)

Mostly a novelty, but I find it's rather neat to see all the different ways programming languages accomplish that specific task.
Also, of course, useful for finding the dead basics of a new language you've come across.

### [HTMX](https://htmx.org/)

A neat take on web dev, focusing entirely on writing HTML and sticking to a rather classic approach to handling websites. This
site was originally written with it!

### [ImHex](https://imhex.werwolv.net/)

A kinda neat hexadecimal viewer/editor that lets you parse out/highlight patterns.

### [Svelte(kit)](https://svelte.dev/)

My web development framework of choice. It feels super approachable to someone who longed to have all of the coding be in one file
together, as a lot of it is just HTML files with extra powerful scripting and styling sections that get mushed together rather
effectively in the end.

### [Webmaster Resources](https://sadgrlonline.github.io/archived-sadgrl.online/webmastery/webmaster-links.html)

A useful collection of resources that I check from time to time. The page is archived and thus won't be updated, but there's
definitely some timeless resources to work off of.

## Hosting and Systems Administration

### [Arch Wiki](https://wiki.archlinux.org/)

Yes, I know, it's specifically for Arch Linux, but it's honestly a rather well put together source of information for lots of
linux-specific software. It might not directly solve your problem, but it may give you a good lead to follow.

### [Awesome-Selfhosted](https://github.com/awesome-selfhosted/awesome-selfhosted)

I go over this list every once in a while to see if there's something new I might want to host. Doesn't really provide documentation
on anything, but it's a useful resource for finding alternatives to other pieces of software. See also [awesome-sysadmin](https://github.com/awesome-selfhosted/awesome-selfhosted)

### [IP Subnet Calculator](https://www.calculator.net/ip-subnet-calculator.html)

I really should just know most of this offhand, but I always end up going here to find out what subnets have which addresses, what
the ~~broadcast~~ addresses are, etcetera. Supports ipv6, too! an ATM

### [Porkbun (Registrar)](https://porkbun.com/)

Do you want a website? Your answer should be yes. Everyone should have a website. Do you want a domain name? Well, maybe you're better off
just getting a free [neocities](https://neocities.org/) page, but otherwise, you should get a domain name. They're surprisingly cheap!
I get all of mine through Porkbun, handling the DNS through [Cloudflare](https://cloudflare.com). Namecheap might be a little cheaper on the
first year (thanks Snapps for [reminding me](https://stellers.gay/blog/resources#comment-2) that they definitely do jack up prices after the
first year, I usually do the first year with namecheap and then switch to porkbun), but otherwise I prefer using Porkbun.

_Sidenote, by cheap, I mean... you can get a .com site for as cheap as $12 USD a **YEAR**. That works out to a dollar a day if you don't know elementary math._

### [Virtual x86](https://copy.sh/v86/)

Freaking. Useful. Run old or low-hardware-requirement OSes from Windows 95 to modern Arch Linux in your browser. I did the entirety
of a college course on Linux using only v86.

### [WinWorld PC](https://winworldpc.com/)

A rather nice library of old software, notably operating systems. I haven't used it in a while, but it's a pretty decent source.

## Learning Computer/Electrical Engineering

### Datasheets

The foremost source for any information to do with electronics. Even if you have a library that handles everything for you,
it's best to find the original source of truth so you know for CERTAIN why and how everything does what.

### [Digital](https://github.com/hneemann/Digital)

A tool for creating digital logic circuits. Basically the NANDGame or Turing Complete sandbox on steroids. I'm midway through
making a simple 8-bit CPU at the moment. One day I'll finish it!

### [NANDGame](https://nandgame.com/)

I've always heard that [Turing Complete](https://store.steampowered.com/app/1444480/Turing_Complete/) was a really good and
fun game, but I never got around to buying it. I learned the same lessons through this, which seems to be a less glamarous
and far simpler version that still covers the fundamentals of building a CPU from the very basics of relay/transistor logic
and abstracting your previous work away into components that you build into more and more complex ones.

### [Putting the "YOU" in CPU](https://cpu.land/)

Truth be told it's been years since I went through this one, but I remember it putting the operations performed by a CPU into
more understandable terms. It's got a slightly steep learning curve, but it's very useful if you can climb it.

### [Ben Eater (Youtube)](https://www.youtube.com/@BenEater)

Ben Eater is freakin' awesome. A [breadboard computer](https://www.youtube.com/playlist?list=PLowKtXNTBypGqImE405J2565dvjafglHU),
a [crash couse on computer networking](https://www.youtube.com/playlist?list=PLowKtXNTBypH19whXTVoG3oKSuOcw_XeW), and even
just plenty of videos on the basic function of computer-related electronics. Honestly, I don't think they really go over
modern microcontrollers or anything, but the knowledge you can learn is invaluable if you want to start with computer
engineering/microelectronics.

### [Electroboom (Youtube)](https://www.youtube.com/@Electroboom)

I've watched him for AGES. He's funny as all getout and honestly teaches lots of very useful information that is applicable
mainly to electrical engineering, but computer engineering is just more intricate electrical engineering. In particular,
his videos on individual electronic components were super useful to me.

### [Clabretro (Youtube)](https://www.youtube.com/@clabretro)

Focuses on retro networking hardware, a niche I didn't know I was absolutely fascinated with until watching some of their videos.
I never thought I would be so interested in how dial-up and other early networking tech worked, but it's truly amazing how
all of it works.

### PCBs

#### [KiCad](https://www.kicad.org/)

Brilliant suite of software that lets you go through the entirety of the PCB design process and output files that you can
get printed.

#### [JLCPcb](https://jlcpcb.com/)

I don't like advertising paid services, but this is the service I use to print PCBs. Mostly because it's the cheapest, though
shipping is either very expensive or very slow.

## Mechanical Engineering & General Tech

This subject isn't really my forte, but it's fascinating nonetheless. These resources are likely a lot less in-depth than the rest,
but nonetheless, they've taught me quite a lot.

### [Camden Bowen (Youtube)](https://www.youtube.com/@CamdenBowen)

Guy who makes engines out of 3D printed parts and as of recently, home-machined metal. I learned quite a lot about how engines
work as well as the process of machining from watching him work.

### [Garbage Time (Youtube)](https://www.youtube.com/@GarbageTime420)

Loud aussie man shouts at cars. Definitely on the entertainment side of things, but watching Wade and James work (mostly James)
has certainly taught me a lot more about cars than I ever knew before. Got me into them in the first place, as well.

### [Technology Connections (Youtube)](https://www.youtube.com/@TechnologyConnections)

Probably one of my favourite youtubers of all time. Alec provides so much useful knowledge related to tech, from air
conditioners (at least three different explanations of the refrigeration process, by my count), to cars, to photography
and filmography, and so so so much more. I beg you to watch all the videos you can, I know I have.

One video in particular stands above the rest of them for me, [the video where Alec takes apart an old pinball machine](https://www.youtube.com/watch?v=ue-1JoJQaEg).
I think it really opened my eyes to the fact that electrical engineering, mechanical engineering, and computer engineering,
at the basest level, are all pretty much one and the same. Seeing relays, components, all sorts of tricks being used to form a crude
logical computer without any modern digital ICs or similar truly changed how I went about pretty much all three of the fields.

### 3D Printing & CAD Resources

#### [Octoprint](https://octoprint.org/)

My 3D printer controller of choice. I just have a RasPi 3B+ set up between my two printers and let it control both. I've never
tried to print with both at once (though they're both old and cheap so that would be terrible no matter what), but otherwise
it has never failed me.

#### [OpenSCAD](https://openscad.org/)

A rather interesting way of designing 3D objects, based entirely on written code. Tickles my brain a bit, but I've switched
to FreeCAD for the most part.

#### [Marlin Firmware](https://marlinfw.org/)

The firmware I've adapted to run on one of my 3D printers and am trying to get to run on my other one. It's simple and elegant
and just works.

#### [FreeCAD](https://freecad.org)

My 3D CAD software of choice. I know some people don't like it as it's substantially different from other CAD suites, but as
it's the first one I learned, I quite enjoy it.

## Multimedia

### [Avatar Cropper](https://avatarcropper.com/)

Avatar cropper crops avatars. Super nice preview and everything. 10 stars.

### [DeStockd](https://www.destockd.com/)

Very cool site that aggregates all sorts of freely available video (mostly from the US government afaict) in a way comparable
to the stock video sites that would charge exorbitant prices for it otherwise.

### [FFMPEG](https://ffmpeg.org/)

The coolest tool when it comes to working with videos. If you don't want to learn the CLI, there's plenty of GUI frontends available.

When in doubt, `ffmpeg -i video.mov video.mp4` to convert mov to mp4, for example. It'll usually use pretty decent conversion defaults.
My other favourite commands are `ffmpeg -i video.mp4 -an video-noaudio.mp4` to remove audio (`-an` means audio, none), and
`ffmpeg -i video.mp4 -ss 00:05:05 --to 00:06:00 clip.mp4` to extract the parts of the video between 5:05 (minutes, seconds) and 6:00.

### [Handbrake](https://handbrake.fr/)

Useful frontend for ffmpeg and other en/decoders that allow you to do whatever you'd like with your video files.

### [ImageMagick](https://imagemagick.org/#gsc.tab=0)

Pretty much the still image counterpart to [FFMPEG](#ffmpeg), equally as useful. Awesome for converting between formats, colour modes,
and similar.

### [KDEnlive](https://kdenlive.org/)

Rather lightweight but not overly simple video editor. Does me nicely whenever I need to splice and cut videos together, and
seems to be pretty well featured for more advanced stuff.

### [OBS](https://obsproject.com/)

If you're a streamer or wish to record videos and don't use this, you should really consider it. OBS is completely free, performant,
super customizable, runs on everything, and is just cool.

**ALSO**, people who use instant replay tools and such that allow you to save the last X seconds of your screen, you can do the same
on OBS using a feature called replay buffer! Here's [a tutorial on how to set that up](https://obsproject.com/forum/resources/how-to-setup-instant-replay-in-obs-studio.613/).
Or use the [advanced replay buffer plugin](https://joshuapotter.github.io/replay-buffer-pro/) that lets you have more fine grained
control over what to save.

### [VLC](https://www.videolan.org/vlc/index.html)

If you don't use this video player (calling it that is doing it a disservice frankly), you really should. Plays, like, everything.

## Complicated Math and Stuff

### [3blue1brown (Youtube)](https://www.youtube.com/@3blue1brown)

Math that is sometimes so complicated it makes my head hurt, but presented in a way that if I actually listen and
apply what is taught, I learn it enough to make my head hurt less.

### [3D Game Engine Programming](https://www.3dgep.com/)

I guess this technically should be under learning programming, but this is such complicated and specific stuff that generally
revolves around complex math that I'm putting it here. Taught me quaternions!

### [EKF Filter Tutorial](https://simondlevy.github.io/ekf-tutorial/kalman_01.html)

A super useful resource for learning Extended Kalman Filters, basically (in my case at least), they're filters that take multiple
different sources of information, perform some operations on them, and then output a "filtered", combined output that is at
least ideally more accurate or at least less janky than the raw inputs. Learn quaternions first, though!!

## Art/Design Resources

I'm by no means an artist, but I've been attempting to learn for quite a while. Here's some resources I've discovered that have done
me some good in the past.

### [Aseprite](https://www.aseprite.org/)

A pixel art/sprite editor that I think is rather cute. It's not free unless you compile it yourself, however. Also see the slightly
outdated but nonetheless still useful fully freely distributable counterpart, [Libresprite](https://libresprite.github.io/#!/).

### [Coolors.co](https://coolors.co/generate)

Rather useful for generating rather nice looking palettes for use in art, or website design, or design or any other kind. Or just looking
at pretty colours, honestly.

### [Drawabox](https://drawabox.com/)

...yeah, everyone probably knows about this by now. I truthfully have never gotten past lesson 2, but honestly the practice has routinely
steadied my hand and made art easier to do when I put the time into it. The one warning I'd give is to DEFINITELY not expect this to be
a fully-rounded course that will teach you everything. If you do _just_ drawabox, you'll likely find yourself associating art
with the rather taxing exercises and nothing else. They say to do a lot of your own art just for fun at the same time,
and I definitely recommend you heed that warning.

### [Line-of-action.com](https://line-of-action.com/)

This site is pretty nice, giving you a way to learn what the line of action is from a bunch of examples. It's also built to let you practice
figure drawing, and gives all sorts of different subjects like human models (obviously), shapes, animals, and environments. [SketchDaily](https://www.sketchdaily.net/)
is rather similar, and can provide even more references if you're just looking for practice.

### [PureRef](https://www.pureref.com/)

A super useful tool for collecting a bunch of images and arranging them freely, grouping them, and all that. I'll admit that I don't quite
like how abstract it is and have been working on an alternative of my own, but for now, I still use it heavily. See also [Beeref](https://beeref.org/),
a fully open-source (but admittedly more minimalistic) alternative!

### [Solo Artist Curriculum](https://www.soloartcurriculum.com/)

This is a neat resource that lays out a course for someone learning art on their own. It combines a lot of different (mostly) freely available resources
with a timeline and recommended order of progression. I personally have not used it, but it's been tempting to try.

### [Weylus](https://github.com/H-M-H/Weylus)

A woefully under-appreciated tool that lets you use standalone drawing tablets (such as androids and ipads with styluses) as a desktop
computer's screened tablet. Simply streams your desktop to the tablet and relays inputs back. Doesn't need an app on the tablet, just access
to a modern-ish web browser. I'll say the latency leaves a bit to be desired, but it's still really nice if you can get the hardware acceleration
working and have either a wired connection to your tablet (ethernet dongle, USB tethering) or really good wi-fi.

## Random Cool Tools

### [Darebee](https://darebee.com/)

A massive collection of workouts of all types and difficulties that you can do on your own. I try to do some of them when I can.

### [Everyone has JS, right?](https://www.kryogenix.org/code/browser/everyonehasjs.html)

An elegantly put argument on the necessity of progressive enhancement rather than relying entirely on javascript.

Useful site for dialing in your LCD screens a little bit better.

### [Obsidian](https://obsidian.md/)

A "vault" of markdown-based documents that let you organize notes, stories, and who knows how much else. Extremely extensible with plugins,
including things like tabletop RPG tools, scripts and automation, automatic synchronization, styling, kanban boards, and much much more.

### [RetroArch](https://www.retroarch.com/)

Pretty much a standard frontend for all sort of different video game console emulators.

### [Scaling One Million Checkboxes](https://eieio.games/blog/scaling-one-million-checkboxes)

An interesting read on scaling. I learned some useful lessons on how to make an infrastructure more able to scale,
not that I've needed it as of yet, hahah.

### [The Boring Internet](https://www.terrygodier.com/the-boring-internet)

A neat little essay on protocols and what made and still makes the internet work: the underlying protocols such as HTTP,
NTP, SMTP, and others.

### [Writer](https://writer.bighugelabs.com/)

Maybe a bit silly, but I always liked the distraction-free nature of this rather simple online text editor. The clicks
and dings of the typewriter tend to help drown out the noises around me that might distract me otherwise, without
being distracting themselves as they match the rhythm of my own thinking.

### [Zine Arranger](https://nashhigh.itch.io/zinearranger)

A useful little tool that allows you to arrange a bunch of pages onto one sheet of paper in such a way that
it can be folded to create a booklet (like how Zines were/are made). I find it useful for printing out datasheets.

## Final advice

The one main thing that I know for certain needs to be told to anyone learning to code, learning microelectronics, or really
pretty much any other field is...

Find a project. Doesn't need to be a big one, doen't need to be strictly useful, certainly doesn't need to be something
that will make a lot of money or get super popular. Find something that you love working on and are excited to see
grow and change. For me, it was [Space Station 13](https://spacestation13.com/). Just by undertaking a project, I was thrust
into learning how to use linux, how to code, how to lead a community, and so much more. And it didn't even feel like work.

If all goes to plan, one day, you'll wake up, and realize that you know how to do the things you have always wanted to do,
without even directly working towards it. There's still infinitely more to learn, but at least you've got a great start, and
hopefully, some good memories.
